# CorpTimer guide audit — 2026-10-29

Scope: all 43 timer guides (44 public pages including the directory). Existing visual identity preserved.

## Corrections

- Replaced generic instructions that referred to absent controls with mode-specific button references.
- Removed obsolete claims that standalone timer settings cannot sync with Google. Explained saved-setup sync separately from live-clock synchronization.
- Corrected Darkroom agitation reminders and Running Coach early handoff wording.
- Distinguished CSV readings from JSON configuration export, Stop from Reset, elapsed-time alarms from remaining-time warnings, and meeting clock corrections from extensions.
- Added a worked example and further uses per page, 43 current browser screenshots with numbered controls and keys, and full-size numbered SVG views. Captions and controls remain selectable HTML; screenshot annotations are vector geometry over real screenshots.
- Replaced slogan-like metadata and template/directory copy with functional descriptions. No AI detector score is claimed.

## SEO and usability

Guides are present in static HTML inside a closed disclosure. Each has a unique page title and canonical URL, a descriptive first paragraph, practical example, settings reference, screenshot alt text and anchor navigation. WebApplication structured data describes the tools; no rich-result eligibility is promised. Sitemap has 44 URLs. Screenshot dimensions preserve aspect ratio. Mobile guide references stack into one column.
