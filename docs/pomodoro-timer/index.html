    How it works and advice
    Setup · Controls · Example

    How the Pomodoro Timer works

    This Pomodoro timer alternates focused work with planned breaks. The starting setup has four 25-minute focus sessions, 5-minute short breaks and a 15-minute long break after the fourth session. Focus, short break and long break are entered in minutes and can all be changed.

    Name the task, set the number of focus sessions and choose how often a long break appears. Include a break after the last session if you want a complete work-and-recovery sequence, or turn that option off to finish at the end of the last focus interval.

    Automatic transitions start the next interval when the current one ends. Turn them off if you prefer to decide when work or a break should begin. Pause preserves your place, and the interval plan shows what comes next. A saved setup keeps your chosen rhythm for another session.

    Set up and run the timer

    1. Review the preset and timing fields. Countdown has separate hours, minutes and seconds; interval work/rest uses seconds, while Pomodoro focus/break uses minutes.
    2. Tap a duration number for the circular dial. Turn clockwise to add time or counterclockwise to subtract, then Apply. You can also type a number. Close discards the dial draft.
    3. Choose Alarm sound and Volume, then Test sound. Warning is seconds remaining; Final countdown adds beeps. Zero disables a cue. Stage transition tick and Set alarm have separate switches.
    4. Start begins, Pause holds and Resume continues the run. Reset restores the configured beginning and unlocks duration editing.
    5. Drag the separate timeline below the clock to correct the position. It pauses on release; check the slot and time before resuming.

    Controls at a glance

    Start / Pause / Resume / Start again
    Begins, holds or continues the current run. Start again repeats the completed countdown plan.
    +1 minute
    Extends the active interval without adding a new one.
    Next interval / Continue
    Next interval skips ahead; Continue starts a slot waiting for manual handoff.
    Reset
    Stops and returns to the configured beginning. Reset before changing durations.
    Timeline
    Drag to correct elapsed time, then Resume. The in-clock strip displays progress.
    Set alarm / Alarm at / Test alarm
    Enable an extra bell, drag Alarm at to an elapsed-time position and test it. This bell has its own switch, separate from stage sounds and Stage transition tick. Keep the tab open.
    Fullscreen
    Enlarges the dark clock. Leave with the exit control or Escape where supported. Phone and browser support varies.

    Settings and saved setups

    Alarm sound / Volume / Test sound
    Choose gong, bell, beep or Off, set volume and test without starting the clock.
    Save current as template / Load a saved setup…
    Enter a name and choose Save setup; Cancel closes the naming dialog. Choose a saved name to load that configuration. Reusing a name replaces that template. Templates store settings, not timing reports.
    Remove saved setup
    Removes the selected named configuration, not the timer page.
    Export / Import
    Export downloads a JSON setup; Import loads a setup exported from the same timer type. Export CSV, where present, downloads results instead.
    Outlined star / Make start timer
    The star adds this page to the favorites row on the main page and other timers. Press it again to remove it. Make start timer chooses the timer that opens from the home page.
    Sign in with Google / Sign out / My timers / Load synced settings
    The account control signs in or out. My timers lists saved custom timers. Load synced settings loads received account changes; pause a running timer first.
    Keyboard shortcuts
    Space starts or pauses. Shortcuts are inactive while focus is inside a control.
    Focus / Short break / Long break / Long break every… sessions / Focus sessions
    Lengths are minutes. Long break every chooses how many sessions precede a long break. Include a break after the last session controls whether the plan ends with work or recovery.
    Warning / Final countdown
    Warning is seconds remaining in a work slot; Final countdown is the last few beeps. Zero disables each cue.
    Stage transition tick
    Turns the short handoff click on or off separately from stage alarms.
    Move to the next interval automatically
    Starts the next slot at its deadline. Turn it off to wait for your handoff.

    Example: four focus sessions

    Focus 25 minutes, Short break 5, Long break 15 every four sessions, four Focus sessions and the final break included gives 130 minutes. Disable automatic transitions to decide when each next interval begins.

    Practical advice

    • Choose one concrete task before pressing Start, such as outlining a page or reviewing one chapter.
    • Keep a note for interruptions so you can return to them after the focus interval.
    • Make breaks distinct from the task instead of filling them with another unfinished work item.
    • Shorten or lengthen the focus interval to suit the task; 25 minutes is a starting point, not a requirement.
    • Use manual transitions if a break needs to finish before you are ready to resume work.

    Saving, sound and browser limits

    Settings, named templates, custom timers and favorites save in this browser. Sign in with Google at the top right to sync saved setups. If Load synced settings appears, pause before loading. Saved-setup sync does not synchronize live clocks across devices.

    Keep this tab open and test sound on the device you will use. Phones and browsers can delay alarms in background tabs or while locked. Reload restores saved clocks paused; closing the page does not keep a live alarm running.
