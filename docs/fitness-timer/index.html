    How it works and advice

    Step by step: Fitness Timer

    1. Set the timing using the controls beside the clock. Choose a suitable preset when available, then adjust it to your session.
    2. Tap a duration number to open the circular dial. Turn clockwise to add time or counterclockwise to subtract, then Apply. You can also type a value; Close discards the draft.
    3. If you need an alarm, choose its sound and volume and press Test sound. Turn sounds off for quiet work.
    4. Press Start to begin and Pause to hold the clock. Reset returns the session to its beginning. For a stopwatch, Lap records a split while running.
    5. Drag the timeline to correct the time, then resume when ready. Fullscreen enlarges the clock without moving the account controls into the timer.
    6. Save current as template to reuse the setup. The outlined red star adds the timer to favorites; press it again to remove it.

    When to use this timer

    • Tabata work and recovery intervals.
    • A circuit with a different movement in each work slot.
    • EMOM practice with one scheduled start per minute.

    How the Fitness Timer works

    The fitness interval timer alternates work and recovery for a complete workout plan. Set rounds per set, the number of sets, preparation and cool-down. Rest controls recovery between rounds, while Set recovery controls the longer pause between sets. Individual round settings let you name movements and vary their durations.

    Tabata starts with eight 20-second work intervals separated by 10-second rests. HIIT starts with ten 40-second efforts and 20-second recoveries. EMOM creates ten one-minute intervals with no separate rest: finish your planned repetitions during the minute and use the remainder as recovery. AMRAP starts as one uninterrupted 20-minute work interval. These are editable timer presets, not personalized training recommendations.

    Press Start to run the plan, Pause when needed and Next interval to move ahead. Sounds, warning cues and automatic transitions are configurable. Save or export a setup to repeat the same timings later.

    Advice for using the Fitness Timer

    • Choose movements, equipment and an appropriate pace before starting the clock.
    • Use preparation time to clear your space and check that the alarm is audible.
    • Give circuits multiple sets when you need a separate, longer recovery between repeats.
    • In EMOM mode, work and recovery share the same minute; do not add an extra rest interval unless you intend to change that structure.
    • Use descriptive individual-round names when a circuit changes exercises.

    Useful details

    Can I repeat a circuit for several sets?

    Yes. Choose rounds per set and the number of sets, then set recovery between sets separately from rest between rounds.

    Are settings synchronized with my meeting account?

    These standalone tools keep their own settings and saved setups in this browser. They do not use Google/Firebase meeting synchronization. Export and import a setup to transfer it to another device.

    Will this timer work if I close the page?

    Keep the timer tab open. Browsers can suspend background tabs, especially on phones. Elapsed time is recalculated when the page resumes, but an alarm at the exact deadline cannot be guaranteed. Reloaded interval, stopwatch and chess sessions return paused; the New Year countdown follows its selected date and time zone.
