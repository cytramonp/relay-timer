Guardar una configuración de temporizador

La versión gratuita funciona sin cuenta. Ajusta el tiempo, comprueba el sonido y usa la pantalla completa cuando necesites un reloj más grande. Guarde una configuración en su navegador o expórtela para otro dispositivo.
