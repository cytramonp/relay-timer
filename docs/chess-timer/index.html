How it works and advice

Step by step: Chess Timer

  1. Choose a time-control template and adjust the time per player, increment and delay.
  2. Press Start match. Tap the active player clock to finish a turn and pass time to the other player.
  3. Pause to hold the game. Reset clears the match and returns both players to the configured time.
  4. Each player has a separate time-bank slider. Adjusting it pauses the match so you can check the correction.

When to use this timer

  • A casual two-player match.
  • Blitz practice with increment.
  • A training game using a delay before time is charged.

How the Chess Timer works

The online chess timer gives White and Black independent clocks. Choose a time-control preset or enter starting time in hours, minutes and seconds. Select who moves first, then press Start match. Tap the active player clock after a move to stop that clock and start the opponent’s.

Increment is added to the player’s remaining time after a completed move. Delay is a grace period at the beginning of each turn before that player’s time starts decreasing. The two settings are independent and can be used together. Pausing preserves unused delay for the current turn.

Space switches players during a running match when focus is outside an input or button. Swap sides changes the visual arrangement without changing the clocks. Move counts track completed handoffs. When a player’s time reaches zero, both clocks stop; reset the match to play again.

Advice for using the Chess Timer

  • Agree the starting time, increment and delay before the first move.
  • Place the device where both players can comfortably reach the active clock.
  • Tap once after completing your move and check which clock is active.
  • Pause for a genuine interruption instead of letting one player lose time while the game is stopped.
  • Keep the page open and use a dedicated physical clock when your event requires one.

Useful details

What is the difference between increment and delay?

Increment adds time after a completed move. Delay gives a player a grace period at the start of each turn; unused delay is not added to the clock.

Are settings synchronized with my meeting account?

These standalone tools keep their own settings and saved setups in this browser. They do not use Google/Firebase meeting synchronization. Export and import a setup to transfer it to another device.

Will this timer work if I close the page?

Keep the timer tab open. Browsers can suspend background tabs, especially on phones. Elapsed time is recalculated when the page resumes, but an alarm at the exact deadline cannot be guaranteed. Reloaded interval, stopwatch and chess sessions return paused; the New Year countdown follows its selected date and time zone.
