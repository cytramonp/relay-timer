So funktioniert Besprechungstimer

Der CorpTimer Meeting Timer verwandelt eine Tagesordnung in einen gemeinsamen Zeitplan. Fügen Sie Referenten, Diskussionsthemen oder beides hinzu, geben Sie jedem Slot eine Dauer und wählen Sie die Gesamtdauer des Meetings. Beginnen Sie mit einer Vorlage für ein Standup, eine Retrospektive, eine Planungssitzung oder einen Workshop oder erstellen Sie Ihre eigene Agenda.

Slots enden an Meilensteinen, die ab dem Beginn des Meetings gemessen werden. Wenn eine 8-Minuten-Runde nach 7 Minuten endet, erhält der nächste Redner diese freie Minute. Eine Überschreitung verbraucht Zeit aus späteren Slots. Verwenden Sie „Nächster Redner“, um zu übergeben, „Pause“, um die Besprechungsuhr anzuhalten, und „Rückgängig“, um den letzten Wechsel rückgängig zu machen. Sie können bei Null auf den Host warten oder automatische Übergänge aktivieren.

Der Float-Timer öffnet eine kompakte Anzeige, sofern der Browser dies unterstützt. Live Link erstellt einen Zielgruppenlink; Lassen Sie die Host-Registerkarte geöffnet. Notizen und Berichte bleiben privat. Besprechungen werden in diesem Browser gespeichert, mit optionaler Google-Anmeldung für eine synchronisierte Besprechungsbibliothek.

Richten Sie den Timer ein und führen Sie ihn aus

  1. Wählen Sie unter „Vorlagen“ eine Agenda aus oder verwenden Sie „Erstellen“. Neues Meeting erstellt ein separates Meeting.
  2. Tippen Sie auf eine Dauerzahl für die kreisförmige Wählscheibe. Drehen Sie im Uhrzeigersinn, um die Zeit zu addieren, oder gegen den Uhrzeigersinn, um sie zu subtrahieren, und klicken Sie dann auf „Anwenden“. Sie können auch eine Zahl eingeben. Schließen verwirft den Wählentwurf.
  3. „Sprecher hinzufügen“ und „Thema hinzufügen“ erstellen Agenda-Zeilen. Legen Sie die Zeilenminuten oder Gesamtminuten fest und überprüfen Sie dann den Plan, bevor Sie beginnen.
  4. Mit der Besprechung beginnt die Tagesordnung. Der nächste Redner übergibt, Pause hält die Zeit und „Rückgängig“ macht den letzten Wechsel rückgängig. Wählen Sie „Wenn die Zeit vor der Sitzung abgelaufen ist“.
  5. Verwenden Sie Live Link für eine Betrachterseite oder Vollbild für den Raum. Keep the host tab open.

Bedienelemente auf einen Blick

Vorlagen / Neues Meeting
Vorlagen ändern die aktuelle Agenda. Neues Meeting erstellt ein weiteres Meeting; Erstellen öffnet einen neuen Vorlagenentwurf.
Meeting starten / Nächster Redner
Beginnt mit dem Plan oder übergibt ihn frühzeitig, um die Zeit für spätere Meilensteine zu vertreiben.
Pause / Fortsetzen / Rückgängig machen
Hält die Besprechungszeit an oder setzt sie fort oder macht die letzte Übergabe rückgängig.
Zurücksetzen
Startet den Plan neu und löscht diesen Lauf; Exportieren Sie den Bericht bei Bedarf zuerst.
Wenn die Zeit abgelaufen ist / um 1 Minute verlängern
Warten Sie, bis der Host weiter über Null zählt. Der automatische Modus schaltet zu einem bestimmten Zeitpunkt weiter. Durch Verlängern um 1 Minute wird die aktuelle Zulage geändert.
Float-Timer / Zurückbringen
Öffnet eine kompakte schwebende Anzeige, sofern unterstützt, oder fügt sie wieder in die Seite ein. Prüfe, ob dein Bildschirmfreigabemodus dieses Fenster einschließt.
Live-Link / Teilen beenden
Jeder mit dem Viewer-Link kann die veröffentlichte Agenda und den Timer sehen. Notizen, Besitzer und Berichte bleiben privat. Über eine separate Steuerverbindung kann der Timer gesteuert werden; Geben Sie es nur einem Co-Gastgeber. „Teilen beenden“ widerruft Links; sie verfallen nach 24 Stunden.
Vollbild
Vergrößert die dunkle Uhr. Verlassen Sie den Ort mit der Ausgangskontrolle oder „Escape“, sofern dies unterstützt wird. Die Telefon- und Browserunterstützung variiert.
Sprecher hinzufügen / Thema hinzufügen / Kopie speichern
Fügt Agendazeilen hinzu oder führt einen separaten Besprechungsplan. Zeilensteuerelemente können Elemente umbenennen, neu anordnen oder entfernen.
Gleiche Zeiten / Proportionen beibehalten / Gesamt, min
Equal Times verteilt unfertige Redner und Themen neu. Proportionen beibehalten steuert die Skalierung, wenn sich die Gesamtsumme ändert. Der abgeschlossene Zeitverlauf bleibt erhalten.
Timeline-Grenzen / Clock-Handle / −1 Min. / +1 Min
Grenzen passen die Agendazuordnung an. Der Uhrgriff und die Minutentasten korrigieren die Besprechungsuhr, im Gegensatz zu „Um 1 Minute verlängern“, bei dem sich ein Zeitrahmen ändert.
Sitzungsbericht / Für später / Element hinzufügen / Zusammenfassung kopieren
Bericht vergleicht geplante und tatsächliche Zeit und bietet Export an. Für spätere Speicherung privater Notizen mit optionalen Besitzern. Element hinzufügen speichert eine Notiz; Zusammenfassung kopieren kopiert die Zusammenfassung der abgeschlossenen Besprechung.
Alarm einstellen / Alarm bei / Alarm testen
Aktivieren Sie eine zusätzliche Glocke, ziehen Sie „Alarm bei“ an eine Position mit abgelaufener Zeit und testen Sie es. Diese Glocke verfügt über einen eigenen Schalter, getrennt von den Bühnengeräuschen und dem Bühnenübergangs-Tick. Lassen Sie die Registerkarte geöffnet.
Klick beim Abschnittswechsel
Schaltet den kurzen Handoff-Klick getrennt von den Phasenalarmen ein oder aus.

Einstellungen und gespeicherte Setups

Besprechung exportieren / Alle exportieren / Importieren / Datenschutz
Laden Sie ein Meeting oder eine Bibliothekssicherung herunter, stellen Sie eine exportierte Datei wieder her oder lesen Sie die Datenschutzdetails.
Umrissener Stern / Start-Timer erstellen
Der Stern fügt diese Seite zur Favoritenzeile auf der Hauptseite und zu anderen Timern hinzu. Drücken Sie erneut darauf, um es zu entfernen. „Timer starten“ wählt den Timer aus, der auf der Startseite geöffnet wird.
Mit Google anmelden / Abmelden / Meine Timer / Synchronisierte Einstellungen laden
Die Kontosteuerung meldet sich an oder ab. Meine Timer listet gespeicherte benutzerdefinierte Timer auf. „Synchronisierte Einstellungen laden“ lädt empfangene Kontoänderungen; Halten Sie zunächst einen laufenden Timer an.
Vorlage duplizieren / Vorlage löschen / Vorlage speichern
„Duplizieren“ behält eine separate Vorlage zum Bearbeiten bei. „Vorlage löschen“ entfernt Ihre gespeicherte Vorlage. Beim Speichern der Vorlage werden der bearbeitete Name, die Slots und das Erscheinungsbild übernommen.
Live-Link erstellen / Viewer-Link kopieren / Live-Bildschirm öffnen / Steuerlink kopieren / Steuerbildschirm öffnen / Teilen beenden und Links widerrufen
Erstellen Sie die Sitzungslinks, kopieren oder öffnen Sie ihre Viewer- und Controller-Versionen oder widerrufen Sie beide. Eine Steuerverbindung gewährt Taktsteuerung; Der Viewer-Link ist für das Publikum.
Sitzungsbericht: CSV exportieren / Bericht kopieren / Drucken
Laden Sie den Plan-Ist-Bericht als CSV herunter, kopieren Sie den Text oder öffnen Sie den Druckdialog des Browsers. Exportieren Sie den Bericht, bevor Sie den aktuellen Lauf ersetzen.
Vorlage verwenden / Anpassen / Erstellen / Vorlage speichern / Abbrechen
Vorlage verwenden wendet eine Agenda an. Anpassen oder Bearbeiten öffnet seinen Entwurf; Wählen Sie einen Namen, Slots, ein Symbol und eine Farbe und klicken Sie dann auf „Vorlage speichern“. Abbrechen lässt die gespeicherte Vorlage unverändert.
Tastaturkürzel für Besprechungen
Mit Fokus außerhalb eines Steuerelements: Leertaste übergibt, P pausiert und Pfeil nach links macht den letzten Schalter rückgängig.

Beispiel: ein 30-minütiges tägliches Aufstehen

Benutzen Sie Begrüßung 3 Minuten, fünf Teamkollegen-Updates von jeweils 3 Minuten, Blocker 10 und Nachbereitung 2. Gesamt: 30 Minuten. Beginnen Sie mit der Besprechung und klicken Sie bei jeder Übergabe auf „Nächster Sprecher“. Eine durch ein frühes Ziel eingesparte Minute geht an den nächsten Slot. Equal Times verteilt nicht abgeschlossene Slots neu, wenn Sie dies auswählen.

Andere Verwendungsmöglichkeiten

  • Sprintplanung mit separaten Entscheidungen
  • Eine Retrospektive mit Abstimmungen und Aktionen

Praktische Ratschläge

  • Benennen Sie Agenda-Slots nach der Entscheidung oder dem Thema, damit jeder sehen kann, wofür die aktuelle Zeit steht.
  • Reservieren Sie einen Schlusstermin für Entscheidungen und nächste Maßnahmen, bevor Sie die Zeit zwischen den Rednern aufteilen.
  • Pin-Zeitabschnitte, die eine feste Zuordnung benötigen; Verwenden Sie „Gleiche Zeiten“, wenn unfertige Redner und Themen die verbleibende Zeit gleichmäßig aufteilen sollten.
  • Testen Sie die schwebende Anzeige in Ihrem tatsächlichen Bildschirmfreigabemodus. Ein schwebendes Fenster ist für das Publikum nicht unbedingt sichtbar.
  • Fügen Sie Tangenten für später ein und exportieren Sie einen Sitzungsbericht, wenn Sie eine Aufzeichnung der geplanten und tatsächlichen Zeit benötigen.
