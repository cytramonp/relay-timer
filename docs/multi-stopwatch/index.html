How it works and advice

How the Multi Stopwatch works

Time six people independently, with individual starts, laps and finishes.

How to use it

  1. Label each participant before starting. Record a lap at each checkpoint.
  2. Open Edit stages to name each phase and change its duration in seconds while the clock is paused. Each clock starts independently.
  3. Pause to hold the current stage, use Next stage to finish early, or Reset to start that clock again. Export CSV for your elapsed times and lap splits.

Practical advice

  • Use Start all for a common start; stop each participant separately.
  • Test the setup before the session.

Try one short test before your session. Keep the device awake and the tab visible; browser alarms are not guaranteed while the device is locked.

Can I use this timer offline?

The clocks run without a server after the page loads. Opening an uncached page still requires a connection. No account is required; this board stays in this browser.
