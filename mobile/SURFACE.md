# Mobile timer workspace

## Scope and visitor mode
Operate. Native iOS/iPadOS and Android timer app; catalog, editor, active clock, programs, results and settings.

## Audience and task
Choose a timer, configure durations, run/pause/advance it, save a reusable program and export results. A returning user should open a saved program quickly.

## Direction
Extend the established CorpTimer editorial world. Use a ruled illustrated catalog, system stack/tab navigation, focused editors and a dark active-clock stage. No new visual identity exercise.

## First viewport
The catalog makes Meeting and the activity timers immediately discoverable. A running session gets a prominent return control. The timer shows its real phase, status, remaining time and Start/Pause/Next controls above the sequence.

## Signature interaction
Meeting Next hands unused time to the following speaker; the new remaining time reflects the shared deadline immediately. Workout programs transition through configured work/rest stages.

## Constraints and unresolved verification
Code-led extension of the user-approved brand and plan. No approved mobile comp or concept seed was needed for this pinned adaptation. Respect system Back, safe areas, large type and OS-native toggles. Browser preview evidence does not establish iOS or Android rendering. Native emulator/device and notification checks remain release gates.
