# Серия «Создай свой таймер»

Формат: запись реального приложения в портретной ориентации, 9:16; английские субтитры для интерфейса и публикации. Оригинал без субтитров и отдельный SRT сохраняются вместе с версией с вшитыми субтитрами. Без сторонней музыки и личных данных. Публикация в соцсетях — отдельный следующий шаг.

## Первые два ролика

1. **Boxing timer:** Timers → Create your timer → рецепт Boxing; показать подготовку, три раунда по 3 минуты и два отдыха по минуте; изменить название, выбрать gong, сохранить, открыть полный экран.
2. **Egg timer:** создать рецепт Egg; показать время приготовления и охлаждения; изменить длительность; сохранить и загрузить; открыть полный экран.

Продолжительность монтажа: ориентир 35–60 секунд. Исходная запись может быть длиннее из-за действий в редакторе. Не ускорять тиканье часов так, чтобы зритель принял его за реальную скорость приложения. Субтитры привязать к фактическим моментам действий, не к заранее выдуманным таймкодам.

## Воспроизводимая запись

Workflow `mobile-custom-tutorials.yml` принимает ID сборки APK, скачивает именно её и записывает действия на одноразовом Android-эмуляторе. Отчёт содержит SHA256 APK, ревизию сценария и статус каждого примера. Ошибка проверки означает незавершённую запись, а не готовый ролик. Покупки и отправка feedback не выполняются.

Для каждого готового ролика перед публикацией проверить: читаемость цифр, отсутствие клавиатуры поверх действия, соответствие субтитров нажатию, отсутствие тестовых ошибок, длительность и финальный кадр. Нативные записи подтверждают UI эмулятора; качество звука и работу на реальном телефоне проверяют отдельно.
