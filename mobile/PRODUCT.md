# CorpTimer mobile beta

## Platform
adaptive

## Stack
Expo SDK 58, React Native 0.88, React 19.3, TypeScript, Expo Router, SQLite local storage, expo-audio, expo-notifications and native Expo UI switches.

## Users and purpose
Meeting facilitators are the primary entry audience. Open Meeting directly, configure participants and topics, adjust the running order, carry spare time forward and inspect actual results. Interval training, focus and other timers remain in a separate tab. The shared-deadline meeting mechanism is inherited from the website.

## Operating context
One active timer on a phone or tablet. No account required. Native OS permissions control local notifications; the app does not promise uninterrupted JavaScript execution in the background.

## Brand commitments
CorpTimer, corptimer.com, original glasses, cream/charcoal workspace, dark teal timer, red/teal accents and existing half-comic illustrations. Upright serif headings; system/Manrope body typography; native navigation and switches. Light by default, with explicit Dark and Use device preferences. The starter name is Meeting; preserve custom names.

## Boundaries
Beta with native iOS/Android source and build configuration. Optional anonymous live sharing publishes only an explicit public projection; private notes, follow-ups and reports stay local. Android includes a permission-based floating module; iOS offers focus within the app. Claim each compile, native interaction and network check only at its recorded scope. Do not claim store publication, signed iOS availability, physical-device validation, Google private-library synchronization or Live Activities. See VALIDATION.md, migration-progress.md and RELEASE.md for actual evidence and gates.
