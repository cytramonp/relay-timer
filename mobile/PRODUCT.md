# CorpTimer mobile beta

## Platform
adaptive

## Stack
Expo SDK 58, React Native 0.88, React 19.3, TypeScript, Expo Router, SQLite local storage, expo-audio, expo-notifications and native Expo UI switches.

## Users and purpose
Meeting facilitators, people who train in intervals, students, teachers and people who need a quick timer. Let them configure a repeatable program, run it with a readable clock and inspect actual results. The shared-deadline meeting mechanism is inherited from the website.

## Operating context
One active timer on a phone or tablet. No account required. Native OS permissions control local notifications; the app does not promise uninterrupted JavaScript execution in the background.

## Brand commitments
CorpTimer, corptimer.com, original glasses, cream/charcoal workspace, dark teal timer, red/teal accents and existing half-comic illustrations. Upright serif display headings; system body typography; native navigation and switches. Automatic light/dark appearance.

## Boundaries
Local beta with native iOS/Android source and build configuration. Do not claim store publication, signed iOS availability, physical-device validation, cloud synchronization, live rooms, system overlay or Live Activities. See README and RELEASE.md for release gates.
